# Arpent.io — Console d'administration

Console interne (Next.js) de modération et de supervision pour Arpent.io : gestion des courses, des guildes, des profils et statistiques.

Documentation complète du projet, prérequis et instructions d'installation : voir le [README principal](../README.md).

## Démarrage rapide

```bash
npm install
cp .env.example .env.local   # renseigner les variables Supabase / Mapbox
npm run dev
```

L'application est accessible sur [http://localhost:3000](http://localhost:3000).
